📲 Cài đặt App APK cho Oppo A71k (Android 7.1.1)

Tối ưu ColorOS 3.2

Gói ứng dụng được tối ưu đặc biệt cho Oppo A71k (Snapdragon 450 · 2GB RAM · Màn hình 16:9 HD · Android 7.1.1): bộ nhớ đệm chống tràn RAM, tăng tốc GPU và giữ màn hình luôn sáng khi xem phim.

⚡ Cách 1: Cài đặt trực tiếp 1 chạm (Khuyên dùng)
Mở tức thì 0.1s · Nhẹ máy
Trình duyệt Chrome trên Android 7.1.1 tự động tạo file APK hệ thống (WebAPK) cài vào điện thoại: Có biểu tượng KhangHub ở màn hình chính, xem phim full-screen không có thanh trình duyệt, hoạt động siêu mượt trên RAM 2GB.
👉 Mẹo thêm: Bạn cũng có thể bấm vào dấu 3 chấm (⋮) ở góc trên bên phải Chrome trên điện thoại Oppo A71k → bấm "Thêm vào màn hình chính" (Add to Home screen) hoặc "Cài đặt ứng dụng".
📦 Cách 2: Gói Native Android APK Studio (Thư mục /android)
minSdk 21 · compileSdk 34
Mã nguồn Android nguyên bản (Java / Android Studio) đã có sẵn trong dự án:
  • Đã cấu hình minSdk 21 tương thích hoàn hảo Android 7.1.1 (API 25).
  • Tự động giữ sáng màn hình khi phát phim (FLAG_KEEP_SCREEN_ON).
  • Tự động xoay ngang toàn màn hình 16:9 HD khi bấm xem video.
  • Có sẵn workflow .github/workflows/build-apk.yml để tự động build file APK phát hành.
🛠️ Cài đặt file APK trên ColorOS 3.2 (Oppo A71k):
1. Mở Cài đặt (Settings) trên Oppo A71k → Chọn Cài đặt bổ sung.
2. Chọn An toàn và Bảo mật.
3. Bật mục "Không rõ nguồn gốc" (Unknown sources) để cho phép cài đặt ứng dụng ngoài CH Play.
4. Nhấp vào file APK để cài đặt và thưởng thức!
